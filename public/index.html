    What a program can reach
    
    
    
      Nothing outside this page exists to a Rill program. There are no strings, no network, no files and no clock but the page's own.
      A program sees only the instruments it names with use, and only the settings, readings, actions and events each one lists below.
      Every number has a unit, checked before it runs. Every value carries where it came from: set
      live modelled simulated
      illustrative, and a result is only as sure as its least sure input.
